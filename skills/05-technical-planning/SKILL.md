# Skill 05: Step-by-Step Technical Implementation Planning
**Trigger:** Breaking down an approved architecture or feature into executable coding tasks.
## Workflow
1. Order tasks by dependency: `Data Schema / Models` → `Core Services / Repositories` → `State / Controllers` → `UI Views & Components` → `Tests & Verification`.
2. For each step, list the exact files to create/edit, functions/classes affected, and verification command.
3. Identify rollback steps so the codebase remains runnable after every single milestone.
