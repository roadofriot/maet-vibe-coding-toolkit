# Skill 18: Safe Structural Code Refactoring
**Trigger:** Cleaning up legacy or messy code without changing external functionality.
## Workflow
1. Verify existing behavior and tests before starting.
2. Refactor in small, atomic steps: extract helper functions, decouple UI from data fetching, consolidate duplicate utilities, and clarify naming.
3. Re-run static analysis and tests after each step to guarantee zero regressions.
