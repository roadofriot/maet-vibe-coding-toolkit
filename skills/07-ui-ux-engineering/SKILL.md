# Skill 07: Premium UI/UX & Design System Engineering
**Trigger:** Creating or improving any user interface (Web, Flutter, Android, Desktop).
## Workflow
1. Define/reuse central theme tokens (Colors, Typography, Spacing, Border Radius, Shadows).
2. Ensure visual hierarchy: primary actions stand out clearly; secondary actions are subtle; destructive actions require confirmation.
3. Build all 5 states for every data view: **Loading**, **Populated**, **Empty (with helpful CTA)**, **Error (with Retry button)**, and **Offline indicator**.
4. Verify keyboard navigation, focus states, color contrast, and responsive layouts across mobile and desktop.
