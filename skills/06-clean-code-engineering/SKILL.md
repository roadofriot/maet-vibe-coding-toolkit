# Skill 06: Clean, Minimal & Maintainable Code Engineering
**Trigger:** Writing or editing any source code.
## Workflow
1. **Clarity over Cleverness:** Write straightforward, readable code with descriptive variable and function names.
2. **Small Units:** Functions should do one thing well (ideally under 40 lines); files should stay cohesive (ideally under 300–400 lines).
3. **Explicit Error Handling:** Return typed results or raise descriptive domain errors; log actionable context without leaking sensitive payloads.
4. **Zero Dead Weight:** Remove commented-out blocks, unused imports, and redundant wrappers immediately.
