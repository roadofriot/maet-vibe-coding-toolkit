# Skill 01: Project Discovery & Context Mapping
**Trigger:** Opening a new or existing codebase, or starting any feature request.
## Workflow
1. Inspect top-level directory structure, README, configuration files, and package manifests.
2. Identify the tech stack, framework version, entry points, routing map, and state management approach.
3. Locate canonical data models, API clients, and environment variable templates (`.env.example`).
4. Summarize the project's current architecture in 5–10 bullet points before proposing changes.
