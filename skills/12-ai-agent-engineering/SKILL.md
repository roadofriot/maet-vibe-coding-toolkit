# Skill 12: AI Agent, LLM & Local Ollama Engineering
**Trigger:** Building AI features, multi-agent systems, Gemini API integrations, or local Ollama workflows.
## Workflow
1. Use structured outputs (JSON schema) for deterministic parsing.
2. Implement graceful fallbacks, token-budget limits, streaming responses, and clear system instructions.
3. Keep API keys strictly in environment variables and sanitize untrusted user prompts against prompt injection.
