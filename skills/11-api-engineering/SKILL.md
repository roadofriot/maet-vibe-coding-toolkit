# Skill 11: REST, RPC & Real-Time API Engineering
**Trigger:** Designing or integrating internal/external APIs.
## Workflow
1. Define clear request/response contracts, status codes, pagination (`limit`/`cursor`), and filtering conventions.
2. Implement resilient API clients with configurable timeouts, exponential backoff retries on transient `5xx`/network errors, and token refresh handling.
3. Consult **Context7 MCP** to verify latest SDK method signatures before coding.
