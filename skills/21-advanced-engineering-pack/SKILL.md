# Skill 21: Advanced Engineering Pack (Skills 21–35 Consolidated)
Contains specialized execution rules for:
- **21. Multi-Agent Orchestration:** Coordinate Architect → Engineer → QA → Security sequentially without file-write conflicts.
- **22. Context Engineering:** Read only relevant files/symbols; exclude `node_modules`, `build`, `.dart_tool`, `.venv`, and binary assets from context.
- **23. Prompt Engineering:** Design deterministic system prompts with structured JSON schemas and few-shot examples.
- **24. RAG Engineering:** Chunk documents semantically, use hybrid search (BM25 + embeddings), and cite retrieved sources accurately.
- **25. Git Workflow Engineering:** Atomic commits, conventional commit messages (`feat:`, `fix:`, `refactor:`), clean branch hygiene.
- **26. Dependency Management:** Lockfile integrity, minimal dependency tree, audit for CVEs and deprecated packages.
- **27. Accessibility (a11y) Engineering:** Semantic labels, screen-reader support, keyboard navigation, WCAG contrast compliance.
- **28. Cross-Platform Engineering:** Shared domain logic across Web, Android, Windows, and Ubuntu Linux with platform-adaptive UI.
- **29. Database Migration Engineering:** Forward-compatible schema evolution, zero-downtime column additions, safe rollback scripts.
- **30. Observability & Monitoring:** Structured logging, performance timing hooks, actionable error boundaries.
- **31. Regression Prevention:** Add targeted test coverage for every resolved bug.
- **32. Technical Debt Management:** Track and isolate workarounds with explicit remediation plans.
- **33. Open-Source License Compliance:** Prefer permissive licenses (MIT, Apache-2.0, BSD); flag copyleft (GPL/AGPL) risks in commercial projects.
- **34. Cloud & API Cost Optimization:** Cache repeated queries, debounce search inputs, batch API calls.
- **35. Token Optimization:** Concise, high-signal code and responses without repetitive boilerplate.
