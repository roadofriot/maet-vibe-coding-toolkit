# Skill 08: Modern Frontend & Cross-Platform UI Implementation
**Trigger:** Implementing React, Next.js, Vite, HTML/CSS/JS, or Flutter UI layers.
## Workflow
1. Componentize reusable UI elements (Buttons, Inputs, Cards, Modals, DataTables, Badges).
2. Prevent unnecessary re-renders (`const` widgets in Flutter, proper memoization/selectors in React).
3. Keep business logic and API calls out of presentation components; bind cleanly via controllers/hooks.
4. Ensure forms have client-side validation, clear field-level error messages, and disabled submit states while submitting.
